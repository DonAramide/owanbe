# OWANBE v1.1 — Sprint 1: Executive Overview Dashboard

**Scope:** UI/UX only · No backend or API changes · EOS components only

---

## What changed

The Super Admin **Overview** tab (`/super-admin`, tab 0) is now an **Executive Overview** dashboard that aggregates existing Phase 10 super-admin APIs into a single enterprise command surface.

### Replaced
- `SuperAdminOverviewScreen` (8 static KPI cards + warning banner)

### New
- `ExecutiveOverviewScreen` with 10 sections per sprint spec
- `executive_dashboard_provider.dart` — parallel API aggregation + client-side derivations
- EOS `EosTimeSeriesChart` — multi-series chart with hover tooltips, zoom, PNG export

---

## Sections delivered

| # | Section | Implementation |
|---|---------|----------------|
| 1 | Global platform health | `ExecutiveHealthCard` — score ring (0–100), 9 subsystems, detail drawer |
| 2 | Executive KPI strip | 13 KPI cards with sparkline, trend badge, period compare, tab drill-down |
| 3 | 30-day revenue | `EosTimeSeriesChart` — ticket/booking/fees/refunds/payouts |
| 4 | Live activity | Audit + security events feed with live badge |
| 5 | Top tenants | Sortable table → Tenant Management tab |
| 6 | Top events | Revenue from finance drill API per event |
| 7 | Top organizers | Leaderboard from tenant detail + organizer drill |
| 8 | Alert center | Incidents, recon, health, security alerts with workspace links |
| 9 | Global search | Sticky top bar — tenants, events, audit, security (client-side index) |
| 10 | Layout | 12-column `ExecutiveGrid`, skeleton loading, collapsible nav rail |

---

## APIs consumed (unchanged)

| Endpoint | Used for |
|----------|----------|
| `GET /super-admin/platform/overview` | KPIs, health score, incidents |
| `GET /super-admin/finance/platform` | Revenue, fees, refunds, payouts, event/organizer drill |
| `GET /super-admin/system/health` | Subsystem status |
| `GET /super-admin/analytics/platform?range=30d` | Growth %, period comparison |
| `GET /super-admin/analytics/platform?range=7d` | Sparkline context |
| `GET /super-admin/tenants` | Top tenants table |
| `GET /super-admin/tenants/:id` | Events + organizers for leaderboards |
| `GET /super-admin/audit/timeline` | Activity feed, revenue chart weights, search |
| `GET /super-admin/security/center` | Alerts, activity, security subsystem |

## How to verify

```powershell
cd mobile
flutter run -d chrome
```

1. Sign in: `superadmin@owanbe.dev` / `123456` at `/staff/login?role=superAdmin`
2. Open **Overview** — executive dashboard loads
3. Click a subsystem chip → detail drawer
4. Click a KPI **View details** → navigates to Finance / Tenants / Health / Security tab
5. Hover revenue chart → tooltip; use export icon
6. Use top search → grouped results navigate to workspace tabs
7. Toggle nav collapse via menu icon in rail header

## Data notes (no API changes)

- **30-day daily revenue** distributes real finance totals across days weighted by audit financial activity (totals are API-accurate; daily split is activity-weighted).
- **Subsystem response times** are derived from health check latency + status (API returns status only).
- **Top events/organizers** use finance drill endpoints for per-entity revenue on top tenants.
