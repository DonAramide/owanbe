# API Endpoint Inventory

Inventory of endpoints mapped to client administration service layers:

- `POST /api/v1/users/:id/suspend` - Suspends active administrator accounts.
- `POST /api/v1/vendors/:id/approve` - Authorizes vendor business listing portfolio.
- `POST /api/v1/platform/maintenance` - Toggles scheduled checkout lockouts.
- `POST /api/v1/broadcasts/dispatch` - Queues in-app push targeting notifications.
