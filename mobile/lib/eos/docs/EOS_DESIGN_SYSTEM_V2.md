# EOS Enterprise Design System v2.0

Visual and interaction model standard for all IIPS products.

## Core Design Tokens

### Spacing Scale
- `spaceXxs` = 4.0
- `spaceXs` = 8.0
- `spaceSm` = 12.0
- `spaceMd` = 16.0
- `spaceLg` = 24.0
- `spaceXl` = 32.0

### BorderRadius Scale
- `radiusCompact` = 8.0
- `radiusMedium` = 12.0
- `radiusLarge` = 16.0

### Color system
- Primary brand identity color: `#5B4CF0`
- Success highlight color: `#16A34A`
- Warning status color: `#F59E0B`
- Danger semantic color: `#DC2626`

## Standardized Workspace Layout
All 360 workspaces inherit from `WorkspaceShell` following the hierarchy:
1. Executive Header
2. KPI ribbon metrics row
3. Primary content tabs
4. Context Drawers host panel
5. Unified Timeline logs
